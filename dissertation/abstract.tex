\chapter*{Abstract}

The rapid growth of scientific literature creates significant information overload for researchers. Traditional keyword search fails to capture complex semantic context, while standard Large Language Models (LLMs) risk hallucination when queried on technical papers.

This dissertation presents \textbf{InsightPaper AI}, an end-to-end Retrieval-Augmented Generation (RAG) system for grounded academic document analysis. Built on an MVC architecture with a Streamlit interface, the system integrates PyMuPDF parsing, sliding-window text chunking, a fine-tuned dense embedder, a cloud-native Pinecone vector index, and Groq API middleware supporting dynamic routing between Qwen 3.6 27B and LLaMA 3.1 8B.

To improve retrieval precision, \texttt{all-MiniLM-L6-v2} was fine-tuned using MultipleNegativesRankingLoss (MNRL) on contrastive pairs from the Kaggle Summarized Research Papers dataset. Benchmarked on 30 held-out papers, fine-tuning improved \textbf{Recall@5 from 23.33\% to 100.00\%} and \textbf{Mean Reciprocal Rank (MRR) from 0.1161 to 1.0000}, achieving rank-1 retrieval for every query at zero latency overhead (12ms).

Generative outputs were benchmarked across token-level F1, dense semantic similarity, and multi-dimensional LLM-as-a-Judge ratings. Prompt grounding eliminated all hallucinations. Qwen 3.6 27B achieved a 5.00/5.00 LLM-as-a-Judge score for analytical depth, while LLaMA 3.1 8B delivered rapid 421.3ms average generation latency, proving contrastive embedder fine-tuning is the critical enabler of accurate academic RAG systems.
