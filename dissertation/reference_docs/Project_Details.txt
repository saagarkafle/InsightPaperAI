Project Title:
InsightPaper AI: A RAG-Based System for Automated Research Paper Analysis Using Fine-Tuned Sentence Transformers, LLaMA 3.1, and Qwen 3.6

Summary of Project (300 words):

This project develops InsightPaper AI, a web-based application that enables researchers, students, and academics to upload scientific research papers as PDFs and interact with them through natural language questions. The system answers user queries based strictly on the content of the uploaded paper, eliminating hallucination and ensuring factual accuracy through a Retrieval-Augmented Generation (RAG) architecture with multi-model LLM selection (Meta's LLaMA 3.1 8B and Alibaba Cloud's Qwen 3.6 27B).

The primary research question is: how effectively can an end-to-end RAG architecture utilising a fine-tuned Sentence-Transformer embedder, Pinecone vector index, and multi-model LLMs retrieve relevant paper contexts and generate accurate, source-grounded answers for academic research papers? Supporting sub-questions investigate the impact of domain-specific fine-tuning on retrieval accuracy, the comparative effectiveness of token-level F1, semantic similarity, and LLM-as-a-Judge evaluation metrics, and the real-time performance of metadata-filtered retrieval.

The methodology combines several techniques. PDF documents are parsed and split into overlapping text chunks using PyMuPDF. Each chunk is embedded into a 384-dimensional vector space using the all-MiniLM-L6-v2 Sentence-Transformer model, which has been fine-tuned on the Kaggle Summarized Research Papers dataset (150 papers, 80/20 train/evaluation split) using MultipleNegativesRankingLoss contrastive learning. Embeddings are stored and searched using Pinecone, a cloud-native vector database. Retrieved context chunks are passed to the user-selected LLM (Qwen 3.6 27B or LLaMA 3.1 8B) via Groq for answer generation, with strict system prompts enforcing source-grounded responses.

The key deliverables are: (1) a fully functional Streamlit web application with PDF upload, semantic search, multi-model selection, automated summarisation, and question-answering capabilities; (2) a fine-tuned embedding model demonstrating measurable improvement over the base model; and (3) a quantitative evaluation framework measuring Recall@K, Mean Reciprocal Rank, token-level F1, semantic similarity, and LLM-as-a-Judge scores.

The project is evaluated by comparing base model retrieval performance (Recall@5: 23.3%, MRR: 11.6%) against the fine-tuned model (Recall@5: 100%, MRR: 100%) on 30 held-out test papers, alongside an empirical multi-model comparison of Qwen 3.6 27B vs LLaMA 3.1 8B.
